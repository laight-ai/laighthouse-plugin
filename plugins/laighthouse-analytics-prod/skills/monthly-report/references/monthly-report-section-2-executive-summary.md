# Monthly Section 2: Executive Summary

**report_type:** `monthly-report` (항상 포함). 신규 MCP 호출 없음. **`assets/prepare.py` 출력의 `digest`**만 근거로
실행 모델이 직접 쓴다 — 응답 파일을 열어 보지 않는다. 근거 수치가 없는 문장(원인 추정, 변경 이력, 예측)은 쓰지 않는다.

**무엇을 어떻게 쓸지(목적·작성 규칙·문장 규칙·예시)는 `guides/executive-summary.md`를 따른다.** 그 파일은 비개발자가
노션(TBWA: 요약 가이드 라이브러리 › Monthly Executive Summary)에서 고치는 가이드의 사본이다. 이 문서는 근거 데이터,
이 플러그인에서 달라지는 점, 빌더 입력 형식만 정한다.

## 근거 (`digest`)

- `기간`: `당월`(1일~기준일)·`전월`(한 달 전체) 라벨.
- `전체`: 당월·전월 값과 `전월 대비`. 지표는 광고비·노출·클릭(+조회수·CPV는 조회수 지표가 있을 때만, 매출·ROAS는
  매출 지표가 있을 때만)·CPM·CTR·CPC다. 효율 지표는 원자 합의 비율이다.
- `예산`: 브랜드 월 예산(`월예산`)과 `소진율`. 목표 예산이 없으면 키가 없다 — 가이드대로 전월 대비 광고비 변화로 쓴다.
- `매체`: 매체마다 당월·전월·`전월 대비`, `광고비비중`, 매체 목표가 있으면 `월예산`·`소진율`.
  가이드의 소진 기준(90% 미만 노랑, 110% 초과 빨강)은 이 `소진율`로 판정한다. 매체 예산이 없으면 `광고비비중`과 전월 대비로 쓴다.
- `매체-캠페인`, `매체-캠페인-광고그룹`, `매체-캠페인-광고그룹-광고`: 단위마다 **당월 광고비 상위 + 전월 대비 광고비 변동
  (절대액) 상위**를 합친 행(이름은 `매체 / 캠페인 / …`). 응답에 없는 차원의 단위는 빠진다. `… 생략`은 빠진 행 수다.
- 전월 값이 `-`이고 `전월 대비`가 `신규`면 전월에 없던 것이다 — 가이드 규칙 4대로 "신규 집행"이라고 쓰고 변화는 쓰지 않는다.
  `중단`은 당월 집행이 없다는 뜻이다.
- 변화율은 digest 값을 그대로 쓴다(소수 1자리, % 지표는 %p). 직접 계산하지 않는다.

## 이 플러그인에서 달라지는 점

- **조회수·CPV가 없는 브랜드**(digest에 `CPV` 키가 없다): 가이드의 CPV 자리에 CPC(매출이 있으면 ROAS도)를 쓰고, CTR·CPM과
  함께 본다. 효율 색 기준(10% 이상 악화 빨강, 개선 초록)은 CPC·CPM 변화에 그대로 쓴다(ROAS는 낮아지면 악화).
- 저장 훅이 없는 호스트(`references/legacy-flow.md`)에서는 digest가 없다 — 받은 계층 응답에서 같은 기준(광고비 상위·변동 상위)으로
  골라 가이드대로 쓴다.

## 빌더 입력

```json
"s2": {"groups": [
  {"title": "소진",
   "lead": "7월 광고비는 <strong>₩90,310,565</strong>로 월 예산 ₩96,000,000의 94.1%를 소진했습니다.",
   "media": [
     {"name": "BRS", "desc": "월 예산 ₩14,000,000 중 ₩17,654,099를 집행해 소진율 <strong>126.1%</strong>로 예산을 넘겼습니다.",
      "bullets": [{"unit": "캠페인", "label": "00_통합(BS)_MO", "text": "광고비 ₩15,351,936로 전월 대비 +35.8% 늘었습니다.", "tone": "red"}]}]},
  {"title": "효율", "lead": "전체 CPC는 ₩1,157로 전월 대비 +9.1%, CTR 0.99%(+0.01%p)입니다.", "media": [...]}
]}
```

- `title`: `소진`·`효율`(화면에 `[소진]`처럼 대괄호를 붙인다). `lead`: 가이드의 첫 문장.
- `media[].name`: digest의 매체 이름 그대로(점 색은 빌더가 붙인다). `desc`: 매체마다 한두 문장.
- `bullets[]`: 가이드 v1.5의 "캠페인"·"광고그룹" 두 묶음 — `unit`에 `"캠페인"` 또는 `"광고그룹"`을 넣으면 빌더가 같은 `unit`이
  이어지는 줄을 작은 제목 하나 아래에 모은다. `label`은 단위 표기 없는 이름(가이드 표기 규칙대로 구분되는 부분만 써도 된다).
  캠페인 차원이 없으면 bullets를 비우고 `desc`만 쓴다.
- `tone`: 라벨 색 — `red`(빨강), `yellow`(노랑), `green`(초록), `neutral`(회색). 가이드의 색 이름을 이 값으로 옮긴다.
- 본문은 `<strong>`만 허용, 다른 태그는 글자로 보인다.
- 예전 형식(`{"bullets": [{"text", "tone"}]}` 카드, `"executive_summary"` 문자열)도 받는다 — `groups`가 있으면 `groups`가 우선이다.
