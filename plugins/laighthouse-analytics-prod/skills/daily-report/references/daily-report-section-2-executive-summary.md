# Daily Section 2: Daily Summary

**report_type:** `daily-report` (항상 포함). 신규 MCP 호출 없음. **`assets/prepare.py` 출력의 `digest`**만 근거로
실행 모델이 직접 쓴다 — 응답 파일을 열어 보지 않는다. 근거 수치가 없는 문장은 쓰지 않는다.

**무엇을 어떻게 쓸지(목적·작성 규칙·문장 규칙·예시)는 `guides/daily-summary.md`를 따른다.** 그 파일은 비개발자가
노션(TBWA: 요약 가이드 라이브러리)에서 고치는 가이드의 사본이다. 이 문서는 근거 데이터, 이 플러그인에서 달라지는 점,
빌더 입력 형식만 정한다.

## 근거 (`digest`)

- `기준일`·`전일`: 비교하는 두 날짜. `지표`: 이 브랜드 응답에 있는 지표 라벨(조회수·CPV는 조회수 지표가 있을 때만,
  매출·ROAS는 매출 지표가 있을 때만 있다).
- `전체`, `매체`: 기준일·전일 값과 `전일 대비`.
- `매체-캠페인`, `매체-캠페인-광고그룹`, `매체-캠페인-광고그룹-광고`: 단위마다 **기준일 광고비 상위 + 전일 대비 광고비
  변동(절대액) 상위**를 합친 행(이름은 `매체 / 캠페인 / …`). 응답에 없는 차원의 단위는 빠진다. `… 생략`은 빠진 행 수다.
- 값이 `-`이면 그날 집행이 없었다는 뜻이다(전일 `-` = 신규 집행, 기준일 `-` = 집행 중단).
- `구분`: 가이드의 기준으로 미리 판정한 값 — `신규 집행`·`집행 중단`·`광고비 급등`(+30% 이상)·`광고비 급락`(-30% 이하)·
  `효율 급변`(광고비 변화는 30% 미만인데 CPV·CPM·CTR이 20% 이상 변함). 해당 없으면 키가 없다. 가이드 작성 규칙 2(빨강)는
  앞의 네 가지, 규칙 3(노랑)은 `효율 급변`에서 고른다.
- 변화율은 digest 값을 그대로 쓴다(소수 1자리, CTR·ROAS 같은 % 지표는 %p). 직접 계산하지 않는다.

## 이 플러그인에서 달라지는 점

- **조회수·CPV가 없는 브랜드**: 가이드의 "조회수와 CPV" 자리에 클릭·CPC(매출이 있으면 매출·ROAS)를, 효율 급변의
  "CPV·CPM·CTR"은 digest에 있는 CPM·CTR(·CPC)로 쓴다.
- **전주 같은 요일 비교**: 이 보고서는 전주 같은 요일 값을 받지 않는다 — 가이드의 전주 같은 요일 문장은 쓰지 않는다.
- **예산 대비 소진 속도**: 가이드대로 쓰지 않는다.
- 저장 훅이 없는 호스트(`references/legacy-flow.md`)에서는 digest가 없다 — 받은 응답에서 같은 기준(±30%·±20%, 신규·중단)으로
  골라 가이드대로 쓴다.

## 빌더 입력

```json
"s2": {"bullets": [
  {"head": "전체", "text": "광고비는 ₩2,973,254로 전일보다 6.8% 줄었고, 매출 ₩19,789,333(+9.9%), ROAS 665.6%입니다.", "tone": "neutral"},
  {"head": "NVSHOP / 04_GT액상(SP)_MO", "text": "광고비가 ₩363,846에서 ₩8,052로 <strong>-97.8%</strong> 급락했습니다. 예산·입찰 설정이 바뀌었는지 확인해 주세요.", "tone": "red"}
]}
```

- `head`: 굵게 표시되는 대상(전체, 매체, `매체 / 캠페인 / 광고그룹`). `text`: 본문 — `<strong>`만 허용.
- `tone`: 점 색 — `red`(빨강), `green`(초록), `yellow`(노랑), `neutral`(회색). 가이드의 색 이름을 이 값으로 옮긴다.
- 불릿은 가이드대로 3~6개. 6개를 넘으면 앞 6개만 그린다.
- 예전 형식(`head` 없는 `{"text", "tone"}`, `"executive_summary"` 문자열)도 받는다.
