## 역할

아래 「답변」을 채팅에 그대로 출력한다. 표의 행·문구·순서를 바꾸거나 줄이지 않고, 앞뒤에 설명을 덧붙이지 않는다.
요청 예시의 `<브랜드>`·`<기준일>`·`<월>`은 자리 표시다 — 특정 브랜드 이름이나 날짜로 바꿔 쓰지 않는다(사용자가 브랜드를 말했어도 목록은 그대로 보여 준다).
외부 요인·Owned Media·예산 조정은 준비 중인 스킬이다 — 요청받아도 다른 스킬로 대신 실행하지 않는다.
스크립트·MCP·Artifact를 쓰지 않는다.
