# Breezm Monthly Section 2: Executive Summary

**report_type:** `monthly-detailed` — **브리즘(airbridge 기반) 전용** (항상 포함). 실무자가
이번 달 무엇을 점검·조치해야 하는지 판단할 수 있도록, **전월(M-1) 대비 변화**와 매체/캠페인
단위의 특이사항 중심으로 쓴다. `executive-monthly`의 Executive Summary(섹션 2)와는 목적과
HTML 골격이 다르다 — 이쪽은 실무 관점의 점검이며 카드 하나 안에 평범한 불릿 리스트
(`<ul><li>`)로 렌더링하고, `executive-monthly`는 임원 관점의 의사결정 포인트를 불릿마다
별도 카드(점 색상 구분)로 렌더링한다. `executive-monthly`의 section-2와 달리 "분기 단위 비교"
항목은 없다 — `monthly`에는 매출 추이(오거닉 vs 광고) 섹션 자체가 없어 분기 비교에 필요한
데이터가 없기 때문이다. 대신 `monthly`만 가진 section-5(캠페인 성과 비교)를 활용한 캠페인
단위 특이사항 항목이 있다.

---

## MCP 도구 호출: `list_promotions` × 1

```json
{ "brand_name": "breezm", "start_date": "당월 1일 30일 전 YYYY-MM-DD", "end_date": "target_date" }
```

- 이 섹션에서 **유일하게 새로 호출하는 도구**다 (나머지 데이터는 아래처럼 다른 섹션 응답을
  재사용한다). `start_date`를 당월 1일이 아니라 **그보다 30일 더 앞선 날짜**로 잡는다 — 당월과
  직접 겹치지 않아도 그 직전에 끝난 프로모션/캠페인이 이번 달 초반 성과에 이월 영향을 줄 수
  있기 때문이다(`executive-monthly`와 동일한 30일 룩백 — 월 단위 보고서이므로 `daily`의 7일
  룩백보다 길게 잡는다).
- 응답에 프로모션이 전혀 없으면(당월과 겹치는 것도, 직전 30일 내 종료된 것도 없음), 관련
  불릿에서 프로모션 언급을 생략한다 — 억지로 "프로모션이 없었습니다" 같은 문장을 추가하지
  않는다.

## 텍스트 생성: 아래 사항을 모두 준수하여, AI가 직접 작성 (`df_dify` MCP 호출 안 함)

⚠️ **`df_dify` MCP 서버는 호출하지 않는다** (브리즘은 이 서버를 쓰지 않는다 — naver 기반 브랜드
전용 도구다). 아래 「MCP 도구 호출」의 `list_promotions` 1회를 제외하면 이 섹션은 새로운 MCP
호출 없이 다른 섹션 응답만 재사용한다.

```

1. 수치 데이터 수집 — 별도 재호출 없이 이미 다른 섹션에서 받은 응답을 재사용한다:
   - monthly-detailed-section-1(목표 달성 현황)의 get_target_progress_v2 응답(google/meta/naver
     3회) — 목표 ROAS. **브리즘은 현재 세 매체 모두 매출(revenue) 목표가 등록되어 있지 않아

     이미 계산해 두었으므로**(기간 매출 ÷ 소진액 × 100, Airbridge 광고 매출 기준) 그 값을

     Naver/Google/Meta Ads 세 행의 M-1 광고비 합과 M-1 매출 합을 각각 구한 뒤 ROAS = 매출

   <분석 항목> 3가지를 **반드시 이 순서대로** 포함한다. 항목 1·2는 각각 정확히 한 문장,
   항목 3은 2~3개의 캠페인을 골라 각각 한 문장씩(총 2~3문장) 쓴다 — 전체 문장 수를 고정하지
   않는다.

3. 캠페인은 **2~3개 정도만** 골라 심층 분석한다 (전체를 다 훑지 않는다) — 광고비 상위이거나

4. 새로운 수치를 지어내지 않는다 — 근거 없는 원인 추정은 "확인이 필요하다" 수준으로만 쓴다.
```

## 응답 데이터 구조

```json
{
  "executive_summary": "26년 7월의 전체 ROAS는 122.4%로, 전월(98.1%) 대비 개선되었습니다.\nMeta Ads 매출이 전월 대비 -19.8% 감소하고 ROAS도 -14.5%p 하락했음 — 6월 25일~30일 진행된 여름 세일이 끝난 직후 반동일 가능성이 있어 확인이 필요합니다.\n검색-브랜디드(Google Ads)는 광고비가 전월 대비 +12% 늘었지만 ROAS는 오히려 -18%p 하락함 — 클릭 품질 저하 가능성이 있으므로 키워드/타겟팅 점검을 권장합니다."
}
```

- `executive_summary` 값이 문자열이면 그대로 `<p>`로 렌더링
- 줄바꿈(`\n`) 기준으로 분리하여 각 줄을 `<li>`로 렌더링

## 렌더링 규칙
- `executive_summary` 문자열을 `\n` 기준으로 split → 각 줄을 `<li>` 태그로 변환
- 빈 줄은 건너뜀
- `⚠`로 시작하는 항목은 `color:#d97706`(주황) 처리 — 예: 목표 미등록으로 평가가 어려운 경우,
  캠페인/매체의 지표가 비정상적으로 나쁜 경우 등 실무자가 주의해야 할 항목에 붙인다
- 강조 수치는 `<strong>` 태그 사용
- 항목은 항상 이 순서(① ROAS vs 목표(또는 전월 대비) → ② 매체 특이사항 → ③ 캠페인
  특이사항 2~3개)로 렌더링한다 — 순서를 섞지 않는다. 전체 문장 수를 고정하지 않는다
  (①·②는 한 문장씩, ③은 선정된 캠페인 수만큼).
