# Breezm Monthly Section 2: Executive Summary

**report_type:** `monthly-detailed` — **브리즘(airbridge 기반) 전용** (항상 포함). 실무자가
이번 달 무엇을 점검·조치해야 하는지 판단할 수 있도록, **전월(M-1) 대비 변화**와 매체/캠페인
단위의 특이사항 중심으로 쓴다. `monthly-summary`의 section-2와 달리 "분기 단위 비교" 항목은
없다(매출 추이 섹션이 없어 데이터가 없음).

> ℹ️ HTML 렌더링(불릿 리스트 변환, `⚠` 시작 줄 주황색 처리)은 빌더가 한다 — 모델은 아래
> 규칙으로 텍스트만 작성해 빌더 입력 JSON의 `s2.executive_summary`(줄바꿈 `\n` 구분 문자열)에
> 넣는다. 강조 수치에 `<strong>`을 써도 된다.

## MCP 도구 호출: `list_promotions` × 1

```json
{ "brand_name": "breezm", "start_date": "당월 1일 30일 전 YYYY-MM-DD", "end_date": "target_date" }
```

- 이 섹션에서 유일하게 새로 호출하는 도구다. `start_date`는 당월 1일보다 **30일 더 앞선
  날짜** — 직전에 끝난 프로모션의 이월 효과까지 보기 위함 (월 단위 보고서라 daily의 7일
  룩백보다 길다).
- 프로모션이 전혀 없으면 관련 문장에서 프로모션 언급을 생략한다 — "프로모션이 없었습니다"
  같은 문장을 억지로 넣지 않는다.

## 텍스트 생성: 아래 사항을 모두 준수하여, AI가 직접 작성 (`df_dify` MCP 호출 안 함)

⚠️ **`df_dify` MCP 서버는 호출하지 않는다** (naver 기반 브랜드 전용 — 브리즘은 안 씀).
`list_promotions` 외 신규 MCP 호출 없음 — 전부 다른 섹션 응답을 재사용한다:

- section-1의 `get_target_progress_v2` 응답 — 목표 ROAS (브리즘은 revenue 목표 미등록이
  기본이라 목표 ROAS N/A가 보통). **M0의 "실제 ROAS"는 section-1 `s1` 계산값을 그대로 재사용**
  (다시 계산하지 않는다).
- section-4(매체 성과 비교)의 매체별 M-1/M0 지표와 변화량. **M-1의 "전체 ROAS"는 section-1에
  없으므로 여기서 직접 구한다** — section-4의 Naver/Google/Meta Ads 세 행의 M-1 매출 합 ÷
  M-1 광고비 합 × 100 (Organic/Others는 광고비가 없어 제외).
- section-5(캠페인 성과 비교)의 캠페인별 M-1/M0 지표와 변화량 (`monthly_campaign_rows.py`
  출력과 원본 응답 기준). **캠페인 단위는 M-1 데이터가 아예 없는 경우가 흔하다** — 비교
  자체가 불가능한 캠페인은 특이사항 후보에서 제외한다.

**분석 항목 — 반드시 이 순서대로**:

1. **ROAS vs 목표** (정확히 한 문장): M0 ROAS가 목표 대비 상회/근접/하회인지 수치와 함께.
   목표 ROAS가 N/A이면(기본 상태 — 브리즘은 운영 특성상 매출 목표를 정하지 않음) 목표 비교
   대신 **M0 전체 ROAS(section-1 실제 ROAS)를 전월(M-1, 위에서 계산)과 비교**해 평가한다
   (예: "26년 7월의 전체 ROAS는 122.4%로, 전월(98.1%) 대비 개선되었습니다.").
2. **매체 특이사항** (정확히 한 문장): section-4의 M-1 vs M0 변화 중 눈에 띄는 것 하나.
   비교 기간과 겹치거나 직전에 끝난 프로모션이 있으면 **프로모션명과 기간을 함께 언급**하며
   연계 서술 (효과가 뚜렷하지 않으면 그 사실 그대로). 없으면 프로모션 언급 없이.
3. **캠페인 특이사항** (2~3개, 각 한 문장): 광고비 큰 캠페인을 우선 검토하되 단순 나열 금지 —
   M-1→M0 변화가 커서 "특이사항"으로 부를 만한 것만 선정. 각 문장에 **원인 가설과 해결
   방향을 간결히** 덧붙인다 (예: "광고비는 늘었지만 ROAS는 하락 — 전환율 저하 가능성, 랜딩
   페이지 점검 권장"). 관련 프로모션이 있으면 명칭·기간과 연계. 뚜렷한 특이사항이 없으면
   억지로 채우지 않는다.

**작성 원칙**: truism 금지(모든 문장은 실제 수치를 근거로), 새로운 수치를 지어내지 않는다,
근거 없는 원인 추정은 "확인이 필요하다" 수준까지만. 실무자가 주의해야 할 항목(목표 미등록으로
평가 불가, 지표가 비정상적으로 나쁜 경우 등)은 줄 맨 앞에 `⚠`를 붙인다.
