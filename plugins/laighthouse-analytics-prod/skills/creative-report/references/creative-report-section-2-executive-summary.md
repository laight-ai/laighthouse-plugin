# Creative Section 2: 소재 Summary

**report_type:** `creative-report` (항상 포함). 신규 MCP 호출 없음. **`assets/prepare.py` 출력의 `digest`**만 근거로
실행 모델이 직접 쓴다 — 응답 파일을 열어 보지 않는다. 근거 수치가 없는 문장은 쓰지 않는다.

**무엇을 어떻게 쓸지(목적·작성 규칙·문장 규칙·예시)는 `guides/creative-summary.md`를 따른다.** 그 파일은 비개발자가
노션(TBWA: 요약 가이드 라이브러리)에서 고치는 가이드의 사본이다. 이 문서는 근거 데이터, 이 플러그인에서 달라지는 점,
빌더 입력 형식만 정한다.

## 근거 (`digest`)

- `기간`·`직전 기간`: 최근 7일(T-6일 ~ T)과 그 앞 같은 길이 7일(T-13일 ~ T-7일). 직전 기간 응답이 없으면 `직전 기간`이
  `없음(비교하지 않는다)`이고 `직전 대비`·`광고비 변동 상위 소재`가 빠진다 — 그때는 직전 비교 문장을 쓰지 않는다.
- `전체`: 선택 매체(`chosen_media`) 소재 합계와 `직전 대비`(변화율, CTR·CVR·ROAS 같은 % 지표는 %p). `신규` = 직전 기간에
  집행이 없었다. 전환·CVR은 전환 지표가, ROAS는 매출 지표가 있을 때만 있다.
- `매체`: 항목 하나(이 보고서는 매체 하나만 본다) — `소재 수`, `성과`(= `전체`), `광고비 상위 소재`(5개, `광고비 비중`과
  `직전 대비` — `신규 집행` = 직전 기간에 없던 소재), `ROAS 우수/저조`(매출이 없으면 `CTR 우수/저조`)·`CPC 우수/저조`,
  `최소 표본`(노출 1,000 이상·광고비가 매체 광고비의 1% 이상 — 우수·저조는 이 소재끼리만 비교한 것. 대상 소재가 2개
  미만이면 우수·저조 키가 없다).
- `광고비 변동 상위 소재`: 직전 기간 대비 광고비 절대액 변화가 큰 소재 5개(`광고비` = `직전 → 이번`, `변화` = 변화율 또는
  `신규 집행`·`집행 중단`).
- `일별 추이`: 매체 일별 광고비의 앞 절반(3일)·뒤 절반(4일) 일평균과 `변화`, `가장 많이 쓴 날`, `집행일 수`. 매체 일별 응답이 없으면 이 키가 없다 — 그때는 추이 불릿을 쓰지 않는다.
- 소재 이름은 `매체 / 소재명`이다(같은 소재명이 여럿이면 `(캠페인 / 광고그룹)`이 붙어 있다). 값은 그대로 옮긴다 —
  직접 계산하지 않는다.

## 이 플러그인에서 달라지는 점

- **매체 하나**: 가이드의 "매체마다"는 `chosen_media` 하나만 쓴다. 가이드의 "같은 매체 평균"은 `전체` 값이다.
- **표로 보기 모드 없음**: 이 스킬은 HTML 보고서만 만든다 — 가이드의 표로 보기 형식(`- **head** — text`)은 쓰지 않는다.
- **`--summary <파일>` 대신 빌더 입력 `s2`**: 가이드 출력 형식의 JSON을 그대로 빌더 입력의 `s2`에 넣는다(파일로 저장하지 않는다).
- **효율 저조 규칙의 "CTR 0.3%p 이상 하락·CPC 20% 이상 상승"**: `광고비 상위 소재`의 `직전 대비`(CTR %p·CPC %)로 판정한다.
- 저장 훅이 없는 호스트(`references/legacy-flow.md`)에서는 digest가 없다 — 받은 응답(소재 total 이번·직전 기간, 매체 일별)에서
  같은 기준으로 골라 가이드대로 쓴다.

## 빌더 입력

```json
"s2": {"bullets": [
  {"head": "전체", "text": "광고비 <strong>₩1,503,360</strong>로 직전 기간보다 224.0% 늘었고, 클릭 3,771회(CTR 0.40%), ROAS 1096.0%입니다.", "tone": "neutral"},
  {"head": "NVGFA_DISPLAY / 스마트채널_스포츠음료", "text": "ROAS 2278.7%로 최소 표본을 채운 소재 가운데 가장 높습니다.", "tone": "green"}
]}
```

- `head`는 굵게 렌더링된다(HTML 태그 없이 글자만). `text`에는 `<strong>`만 쓸 수 있다.
- `tone`이 점(●) 색이다: `red`(빨강) · `green`(초록) · `yellow`(노랑) · `neutral`(회색). 가이드 작성 규칙의 색을 그대로 옮긴다.
- 불릿은 가이드대로 3~6개다.
