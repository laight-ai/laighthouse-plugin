## MCP 도구 호출: `list_promotions` × 1 (이 섹션의 유일한 신규 호출)

```json
{ "brand_name": "breezm", "start_date": "당월 1일 30일 전 YYYY-MM-DD", "end_date": "target_date" }
```

- `start_date`는 당월 1일보다 **30일 더 앞** — 당월 직전에 끝난 프로모션의 이월 효과까지
  보기 위함 (daily의 7일 룩백은 월간 보고서에 너무 짧다).
- 프로모션이 전혀 없으면 (e) 유형 불릿을 만들지 않는다 — "프로모션이 없었습니다"류 문장 금지.

나머지 데이터는 **신규 호출 없이 재사용**한다: section-5가 가공한 매체별 M-1 vs M0 변화량
(핵심 근거), section-3의 6개월 광고비/매출/ROAS 시리즈(다개월 추세), section-4의 6개월 전체/
광고 매출 시리즈(오거닉 비중 변화·분기 비교). section-1은 직접 인용하지 않는다 (브리즘은
매출 목표 N/A가 기본이라 "목표 대비" 프레이밍 불가 — 전부 전월/분기 대비로 쓴다).

**분기 비교 계산법 (신규 호출 없음, section-3/4의 6개월 데이터로 계산)**: 현재 분기(Q)에서
target_date의 월이 N번째 달(N=1~3)인지 구하고, 이번 분기 1~N번째 달 합계 vs 전분기 1~N번째 달
합계를 비교한다 (예: 8월이면 Q3의 2번째 달 → "7~8월 합계" vs "4~5월 합계"). 필요 개월 수는
최대 6개월이라 section-3/4의 데이터 범위 안에서 항상 계산 가능하다.

## 작성 원칙 (AI 직접 작성 — `df_dify` MCP 호출 금지, naver 브랜드 전용 도구다)

각 불릿 = "무슨 일이 있었는지(수치) + 왜 임원이 신경 써야 하는지(시사점)". truism 금지.
아래 다섯 유형을 우선 탐색하되 해당 사항이 있을 때만 쓴다 (억지로 채우지 않는다):

- **a) 예산 재검토가 필요한 성장 신호** — 전월 대비 매출/ROAS가 뚜렷하게 성장한 매체.
  근거 수치 필수. (예: "Google Ads 매출이 전월 대비 +22.4% 성장, ROAS도 240.3%p 개선됨.
  실무자와 원인을 파악하여 예산 확대를 검토할 수 있음.")
- **b) 원인 확인이 필요한 하락 신호** — 전월 대비 뚜렷한 하락 또는 타 매체 대비 열위.
- **c) 효율 변화가 뚜렷한 매체** — 고효율이지만 추세가 꺾이는 중, 또는 눈에 띄게 개선된 매체
  (section-5의 M-1 vs M0 + section-3의 다개월 추세).
- **d) 전체 매출·광고 매출 비중 변화** — 전월 대비 광고 매출 비중 확대/축소 + **분기 단위
  비교**(위 계산법)로 장기 추이를 함께 기술.
- **e) 프로모션/이벤트 영향 (이월 효과 포함)** — **프로모션명과 기간을 반드시 함께 언급**.
  당월과 겹치면 그 기간/직후 성과 변화를 데이터로 확인해 서술. 당월 직전(30일 내) 종료면:
  인지도·노출 확대형(브랜딩/콜라보)은 이월 효과 관점, 단기 할인형은 종료 후 반동(일시 하락)
  관점으로 서술 — 성격이 불명확하면 "~일 가능성이 있다" 수준까지만. 변화가 뚜렷하지 않으면
  그 사실 그대로 쓴다.

- 불릿 수 3~5개 — "정말 중요한 것만". 5개 초과분은 빌더가 잘라내므로 임팩트 순으로 정렬해
  넘긴다.
- 새로운 수치를 지어내지 않는다. 근거 없는 원인 추정 금지 — "확인/점검이 필요하다"까지만.
- 강조 수치에 `<strong>` 사용 가능.

## 빌더 `s2` 필드

```json
{ "bullets": [ {"text": "한 불릿 = 한 특이사항 한 문장(들).", "tone": "up"}, ... ] }
```

| 필드 | 값 |
|---|---|
| `text` | 불릿 본문 (HTML `<strong>` 허용) |
| `tone` | `"up"`(성장/개선, 초록 ●) / `"down"`(하락/점검 필요, 빨강 ●) / `"neutral"`(중립 관찰 — 비중/분기 추이 안내, 효과 불명확한 프로모션, "가능성" 수준 추정. 회갈색 ●, 생략 시 기본값) |

프로모션 불릿은 효과가 뚜렷이 긍정적이면 `up`, 부정적이면 `down`, 그 외 `neutral`.
