# Breezm Executive Creative Section 2: Executive Summary

**report_type:** `creative-summary` — **브리즘(airbridge 기반) 전용** (항상 포함).
**메타(Meta Ads)만 대상.** 임원이 딥다이브 없이 "어떤 소재에 예산을 더 쓰거나 줄여야 하는지"
파악하도록, **광고비 상위 소재의 성과를 전체 평균과 비교**하고 **광고비 효율성** 중심으로 쓴다.

> ℹ️ HTML(불릿 카드 마크업, 점 색상 적용)은 빌더가 한다 — 모델은 아래 규칙으로 불릿 텍스트와
> tone만 정해 빌더 입력 JSON의 `s2.bullets`에 넣는다. 강조 수치에 `<strong>`을 써도 된다.

## 텍스트 생성: AI가 직접 작성 (`df_dify` MCP 호출 안 함, 신규 MCP 호출 없음)

전부 다른 섹션 데이터를 재사용한다:

- section-3의 스크립트 출력(날짜별 전체 클릭/노출/매출/광고비 합의 근거가 된 시리즈)을 7일
  전체로 합산해 **7일 전체 평균 CTR**(7일 클릭 합÷노출 합×100)과 **7일 전체 평균 ROAS**
  (7일 매출 합÷광고비 합×100)를 구한다. 부산물인 **7일 전체 광고비 합**은 아래 비용 효율성
  판단의 분모로 쓴다.
- section-4/5의 상위 5개 소재별 7일 누적 광고비·노출·클릭·매출 → 각 소재의 **7일 누적
  CTR/ROAS** (상위 5개의 7일 합산 cost는 section-1 range_table 응답에 이미 있다 — 재사용).

**분석 항목 — 반드시 이 순서대로**:

1. **상위 5개 소재 성과 평가**: 전체 평균 CTR/ROAS와 비교해 성과가 특별히 높거나 낮은 소재
   1~2개를 기술한다.
2. **비용 효율성 판단**: 그 소재의 광고비가 전체 광고비에서 차지하는 비중을 기술하고, 현재
   광고비가 얼마나 효율적으로 쓰이는지 판단한다.
3. 비효율 지점이 관측되면 권장 액션 아이템을 기술하고 담당 실무자와 논의하도록 권장한다.

**작성 원칙**: truism 금지(모든 문장은 실제 수치를 근거로 — 소재의 실제 ROAS/CTR/광고비/광고비
비중), 새로운 수치를 지어내지 않는다, 근거 없는 원인 추정은 "확인이 필요하다" 수준까지만.
소재는 **2~3개만** 골라 분석한다(광고비를 많이 쓰면서 지표 특이사항이 있는 것 위주) —
특이사항이 뚜렷한 소재가 없으면 상위 5개 전체의 광고비 비중과 전반적 효율에 대한 중립 요약
불릿 하나로 대체한다. 불릿은 보통 2~3개, 4개를 초과하면 임팩트 큰 상위 3개만 남긴다.

## 빌더 `s2` 필드

```json
"s2": { "bullets": [
  {"text": "AD_...은 최근 7일 ROAS가 <strong>388.1%</strong>로 전체 평균(180.4%) 대비 2배 이상 높습니다. ...", "tone": "good"},
  {"text": "AD_...는 광고비가 전체의 9.8%를 차지하지만 ROAS는 62.1%로 ... 논의할 필요가 있습니다.", "tone": "bad"}
] }
```

- `tone`이 점(●) 색을 정한다: `"good"`(전체 평균보다 뚜렷하게 높은 성과, 예산 확대 검토
  대상)=초록, `"bad"`(뚜렷하게 낮은 성과·비효율, 액션 아이템 필요)=빨강, `"neutral"`(특이사항
  없는 중립 요약)=회색-갈색.
