# Breezm Executive Creative Section 2: Executive Summary

**report_type:** `creative-summary` (항상 포함) — **브리즘(airbridge 기반) 전용**.
**메타(Meta Ads)만 대상**이다. 임원이 딥다이브 없이도 "어떤 소재에 예산을 더 쓰거나 줄여야
하는지"를 파악하도록, **광고비 상위 소재의 성과를 전체 평균과 비교**하고 **광고비 효율성**을
중심으로 쓴다. `mtd`/`daily`/`monthly`의 Executive Summary와 달리 **임원용 HTML 골격**(카드
하나 안에 불릿마다 별도 테두리 카드 + 점 색상 구분 — `executive-mtd`/`executive-daily`/
`executive-monthly`와 동일한 방식)을 쓴다. **색깔을 입힌 "승인 필요" 강조 박스(전체
배경색, 버튼, 배지 등)는 만들지 않는다** — 흰 배경의 평범한 불릿 카드로만 구성한다.

---

## 텍스트 생성: 아래 사항을 모두 준수하여, AI가 직접 작성 (`df_dify` MCP 호출 안 함)

⚠️ **`df_dify` MCP 서버는 호출하지 않는다.** 이 섹션은 **새로운 MCP 호출이 전혀 없다** —
아래 다른 섹션들의 응답만 재사용해서 AI가 직접 작성한다.

```
작성 순서:
1. 수치 데이터 수집 — 신규 호출 없음. 전부 다른 executive-creative 섹션 응답을 그대로
   재사용한다:
   - creative-summary-section-3(최근 7일 전체 소재 CTR 및 ROAS)이 계산해 둔
     **날짜별 전체 클릭/노출/매출/광고비 합**을 다시 7일 전체로 합산해서, **7일 전체 평균
     CTR**(= 7일 전체 클릭 합 ÷ 7일 전체 노출 합 × 100)과 **7일 전체 평균 ROAS**(= 7일
     전체 매출 합 ÷ 7일 전체 광고비 합 × 100)를 각각 하나의 값으로 구한다. 이 계산의
     부산물로 나오는 **7일 전체 광고비 합**은 아래 "비용 효율성 판단"의 분모로 그대로
     쓴다. (section-3은 날짜별 시리즈만 갖고 있으므로, 이 섹션에서 그 값들을 7일 치 전체로
     한 번 더 합산하는 것이다 — 새 MCP 호출이 아니라 이미 받은 값의 재가공이다.)
   - creative-summary-section-4(최근 7일 일별 CTR, 광고비 상위 5개 소재)와
     creative-summary-section-5(최근 7일 일별 ROAS, 광고비 상위 5개 소재)의
     일별 시리즈를 각 소재별로 7일 합산해서, **상위 5개 소재 각각의 7일 누적 광고비·
     노출·클릭·매출**을 구하고, 이를 바탕으로 각 소재의 **7일 누적 CTR**(=7일 누적 클릭÷
     7일 누적 노출×100)과 **7일 누적 ROAS**(=7일 누적 매출÷7일 누적 광고비×100)를 계산한다.
     (5개 소재의 7일 누적 광고비는 애초에 이 두 섹션이 "상위 5개"를 뽑을 때 이미 계산해
     둔 값이므로 재사용한다.)
2. dify 호출 없이, 위 수치를 근거로 AI가 executive_summary 텍스트를 직접 작성한다. 아래
   <분석 항목> 4가지를 순서대로 반영하되, 항목 1~3은 선정된 소재 수(2~3개)만큼 불릿을
   구성하고, 뚜렷한 특이사항이 없으면 중립적인 요약 불릿 하나로 대체한다.

<분석 항목>:
1. **광고비 기준 상위 5개 소재 성과 평가**: creative-summary-section-4-daily-CTR,
   creative-summary-section-5-daily-ROAS에서 분석한 광고비 기준 상위 5개의
   성과를 평가한다. 전체 평균 CTR, ROAS와 비교하여 성과가 특별히 높거나 낮은 소재
   1~2개를 기술한다.
2. **비용 효율성 판단**: 성과가 높음 또는 낮음으로 판단된 소재에서 사용되는 광고비가
   전체 광고비에서 차지하는 비중을 기술한다. 이를 바탕으로 현재 광고비가 얼마나
   효율적으로 사용되는지를 판단한다.
3. 만약 광고비가 효율적으로 사용되지 않는 지점이 관측된다면, 권장되는 액션 아이템을
   기술하고 담당 실무자와 논의하도록 권장한다.
4. 새로운 수치를 지어내지 않는다 — 근거 없는 원인 추정은 쓰지 않는다.

<작성 원칙 — 반드시 지킬 것>:
1. truism 금지 — "ROAS가 우수한 소재에 광고비를 늘리면 매출이 늘 것이다" 같은 근거 없는
   일반론은 쓰지 않는다. 모든 문장은 구체적 수치(소재의 실제 ROAS/CTR/광고비/광고비 비중)
   를 근거로 든다.
2. 소재는 **2~3개 정도만** 골라 분석한다(전체를 다 훑지 않는다) — 광고비를 많이
   사용하면서도 지표에서 특이사항이 관측되는 것 위주로 고른다. 특이사항이 뚜렷한 소재가
   없으면 억지로 채우지 않고 있는 만큼만 쓴다(이 경우 상위 5개 전체의 광고비 비중과
   전반적 효율에 대한 중립적 요약 불릿 하나로 대체해도 된다).
3. 새로운 수치를 지어내지 않는다 — 근거 없는 원인 추정은 "확인이 필요하다" 수준으로만
   쓴다.
```

## 응답 데이터 구조

```json
{
  "executive_summary": "AD_260523_urbanshade_vod_01은 최근 7일 ROAS가 388.1%로, 전체 평균 ROAS(180.4%) 대비 2배 이상 높은 성과를 냈습니다. 이 소재의 광고비는 전체 광고비의 4.1%에 불과해, 예산 확대를 검토해볼 만한 여지가 있습니다.\nAD_251114_04는 광고비가 전체의 9.8%를 차지하지만 ROAS는 62.1%로 전체 평균(180.4%)보다 크게 낮습니다 — 광고비 비중에 비해 비효율적으로 운영되고 있는 것으로 보이며, 담당 실무자와 소재 교체나 타겟팅 조정을 논의할 필요가 있습니다."
}
```

- `executive_summary` 값이 문자열이면 그대로 `<p>`로 렌더링
- 줄바꿈(`\n`) 기준으로 분리하여 각 줄을 하나의 불릿 카드로 렌더링

## 렌더링 규칙
- 각 불릿을 감싸는 카드는 흰 배경, 옅은 회색 테두리(`#e2e8f0`)의 **평범한 카드**로만
  렌더링한다 — 색깔을 입힌 강조 배경, 버튼, 배지 등이 있는 "승인 필요" 박스는 만들지
  않는다.
- 앞머리 점(●) 색상(`{DOT_COLOR}`)은 내용의 성격에 따라 구분한다: 전체 평균보다 뚜렷하게
  높은 성과(예산 확대 검토 대상)는 `#16a34a`(초록), 전체 평균보다 뚜렷하게 낮은 성과 또는
  비효율(액션 아이템 필요)은 `#dc2626`(빨강), 특이사항이 뚜렷하지 않아 중립적으로
  요약하는 불릿은 `#78716c`(회색-갈색).
- 강조 수치는 `<strong>` 태그 사용.
- 불릿 개수는 보통 2~3개다 — 4개를 초과하면 상위 3개(가장 임팩트가 큰 것)만 남긴다.
