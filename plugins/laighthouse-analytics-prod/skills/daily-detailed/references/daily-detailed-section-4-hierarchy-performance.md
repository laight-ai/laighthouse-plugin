# Daily Section 4: 매체·캠페인·광고그룹·광고 성과 (D-1 vs D-0, 계층 표)

**report_type:** `daily-detailed` (항상 포함). 매체 → 캠페인 → 광고그룹 → 광고를 ▶/▼로 펼치는
**계층 표** 하나로 **전날(D-1)과 기준일(D-0)**을 비교한다. 시작은 매체 단위로 접혀 있고, 각 행은
그 단위의 합계("전체")다. 봉투의 **모든 지표**를 컬럼으로 보여주며(지표 선택으로 숨길 수 있음),
각 값 아래에 D-1 대비 증감(비율 지표는 `%p`)이 붙는다. 기본 정렬은 광고비 내림차순이고 헤더를
누르면 바뀐다. 광고비 기준 제외 규칙은 없다.

> ℹ️ 트리 생성(레벨 판별·기간 분리·조상 보장·정렬)·표 HTML/JS(펼치기·정렬·검색·지표 선택·
> 더 보기)는 전부 빌더(공용 킷 `build_tree`/`LHKit.treeTable`)가 한다 — 모델은 아래 호출의
> 응답을 **가공 없이 전부** 빌더 입력 `s4`에 넘기기만 한다(`generic-report-pattern.md` 8절).

## MCP 호출 — 레벨마다 따로 (비율 지표를 하위 행에서 합산하지 않기 위해)

모든 호출: `start_date` = target_date-1일, `end_date` = target_date, `time_grain: "day"`,
**`metrics` 생략**(전체 지표).

| 레벨 | `group_by` | `filters` | 횟수 |
|---|---|---|---|
| 매체 | — | — | 0 — **section-3 응답(7일, `group_by:["media"]`)을 그대로 재사용** |
| 캠페인 | `["media", "campaign_name"]` | 생략 | 1 |
| 광고그룹 | `["media", "campaign_name", "ad_group_name"]` | `{"media": ["<media_list 값>"]}` | len(media_list) |
| 광고 | `["media", "campaign_name", "ad_group_name", "ad_name"]` | `{"media": ["<media_list 값>"]}` | len(media_list) |

- 광고그룹·광고는 고카디널리티라 **매체마다 따로** 부른다(통합 호출은 금지된 회귀). 캡처 훅이
  있는 호스트에서는 캠페인 이하 응답이 스텁(`[laighthouse-capture-hook] ... 저장됨: <경로>`)으로
  온다 — 그 파일을 Read하지 않고 경로만 넘긴다.
- `filters.media` 값은 디스커버리 응답 문자열 **그대로**. Organic(`media: null`)은 필터로 지정할
  수 없고 캠페인 구조도 없다 — 매체 레벨(section-3 응답)에서만 한 행으로 나온다(`has_organic`이고
  매출 있음 모드일 때만 표시).
- 호출들은 의존성이 없으므로 section-3 호출과 **한 메시지에서 병렬 발사**한다.
- 매체에 따라 `ad_group_name`/`ad_name`이 비어 있을 수 있다(`(미지정)`으로 표시, 오류 아님).

## 빌더 `s4` 입력

```json
"s4": {
  "json_files": ["<캠페인 스텁 경로>", "<광고그룹 매체1 경로>", "...", "<광고 매체N 경로>"],
  "json": ["<section-3 응답 원문 문자열>"]
}
```

- 스텁으로 온 응답은 `json_files`에, 원본으로 온 응답(보통 section-3 응답)은 `json`에 **문자열
  통째로** 넣는다. 둘을 섞어도 된다. **section-3 응답을 반드시 포함한다** — 빠지면 매체 행이
  값 없이(`—`) 나온다.
- 빌더가 봉투의 `group_by` 접두 길이로 레벨을, 행의 `date`로 D-1/D-0을 판별한다. 모델은 행을
  고르거나 합치거나 옮겨 적지 않는다.

> 🚫 **응답이 크다고 느껴져도 선택지는 둘뿐이다**: (1) 원본을 가공 없이 전부 빌더에 넘기거나
> (2) 정말 불가능하면 `s4`를 빌더 입력에서 빼서 "데이터 준비 중"으로 표시한다. 다른 섹션 값
> 재사용·근사치·추정 수치 대체는 그 숫자가 진짜 쿼리 결과라도 **전부 금지**다.
