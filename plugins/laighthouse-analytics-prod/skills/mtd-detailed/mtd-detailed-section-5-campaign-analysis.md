# Breezm MTD Section 5: 캠페인 분석 (Campaign Analysis)

**report_type:** `mtd-detailed` — **브리즘(airbridge 기반) 전용** (항상 포함). 캠페인별 성과를
표로 보여주는 섹션 7(Campaign별 성과)과 달리, 이 섹션은 **서술형**으로 특이사항과 액션
아이템을 짚는다.

---

## 텍스트 생성: 아래 사항을 모두 준수하여, AI가 직접 작성 (`df_dify` MCP 호출 안 함)

⚠️ **`df_dify` MCP 서버는 호출하지 않는다** (브리즘은 이 서버를 쓰지 않는다 — naver 기반 브랜드
전용 도구다).

```
작성 순서:
1. 수치 데이터 수집 — 새 MCP 호출 없이 다른 섹션 응답을 그대로 재사용한다:
   - mtd-detailed-section-7(Campaign별 성과)의 매체-캠페인별 합산 데이터(노출/클릭/CTR/광고비/
     매출/예약 완료/CPA/ROAS, 캠페인명 정확 일치 조인까지 끝난 값)을 그대로 쓴다.
   - 이 섹션에서만 쓰는 파생 지표는 새 호출 없이 그 자리에서 계산한다:
     - `CPC` = 광고비 ÷ 클릭 (클릭 0이면 N/A)
     - `평균단가`(객단가) = 매출 ÷ 예약 완료 (예약 완료 0이면 N/A)
     - 이 섹션에서 "구매"는 section 7의 `예약 완료` 필드를 그대로 가리킨다 (별도 전환 지표
       없음).
   - mtd-detailed-section-4(일일 매출 현황)의 `list_promotions` 응답 — 이번 달 MTD 기간과
     겹치거나 그 직전에 끝난 프로모션이 있는지 확인용.
2. dify 호출 없이, 위 수치를 근거로 AI가 `campaign_analysis` 텍스트를 직접 작성한다.

<작성 원칙 — 반드시 지킬 것>:
1. **광고비가 큰 캠페인을 우선적으로 검토**하되, 단순히 광고비 순으로 나열하지 않는다 —
   같은 매체 내 다른 캠페인과 비교했을 때 ROAS/CTR/CPC/구매(예약 완료)/평균단가 중 확연히
   높거나 낮은 지표가 있어 "특이사항"으로 부를 만한 캠페인만 고른다.
   ⚠️ **매체를 가로질러 CTR/CPC를 직접 비교하지 않는다** — Google/Meta/Naver는 지면·과금
   구조가 달라 CTR·CPC의 기본 스케일 자체가 다르므로, 같은 매체 내 캠페인끼리만 비교한다.
   ROAS·CPA·예약 완료 같은 성과/비용 지표는 매체 간 비교도 가능하다.
2. 특이사항마다 **원인에 대한 가설과 해결 방향을 간결하게** 덧붙인다 (예: "클릭률은 동일 매체
   내 캠페인 평균 대비 높은 편이지만 예약 전환은 낮음 — 랜딩페이지 단계에서 이탈이 발생하고
   있을 가능성이 있어 랜딩페이지 점검을 권장합니다."). `list_promotions` 응답에 해당 캠페인의
   활동 기간과 겹치거나 그 직전에 끝난 프로모션이 있으면, **프로모션명과 기간을 함께 언급**하며
   연계해서 서술한다 (효과가 뚜렷하지 않으면 그 사실 그대로 쓴다).
3. **truism 금지** — "광고비를 늘리면 매출이 늘 것이다" 같은 근거 없는 일반론은 쓰지 않는다.
   모든 문장은 구체적 수치(캠페인의 실제 CTR/CPC/ROAS/예약 완료 값)를 근거로 든다.
4. 캠페인은 **2~4개 정도만** 골라 심층 분석한다 (전체 캠페인을 다 훑지 않는다) — 광고비 상위
   이거나 지표 이상 신호가 뚜렷한 캠페인 위주로 고른다. 특이사항이 뚜렷한 캠페인이 없으면
   억지로 채우지 않고 있는 만큼만 쓴다.
5. 새로운 수치를 지어내지 않는다 — 근거 없는 원인 추정은 "확인이 필요하다" 수준으로만 쓴다.
```

## 응답 데이터 구조

```json
{
  "campaign_analysis": "광고비 기준 상위 캠페인 중 특이사항이 확인되는 2개를 선정했습니다.\n\n리타겟팅_구매고객 (Meta Ads)\n광고비 ₩9,800,000으로 Meta Ads 내 2번째로 크지만, 예약 완료가 0건으로 매출이 전혀 발생하지 않았습니다. CTR은 3.2%로 Meta Ads 평균보다 높아 클릭 자체는 정상적으로 발생하고 있어, 랜딩페이지 또는 예약 전환 단계에서 이탈이 발생하고 있을 가능성이 있습니다.\n\n파워링크_단백질보충제 (Naver Ads)\nCPC가 ₩636로 Naver Ads 내 다른 캠페인 대비 낮으면서 ROAS는 1,436.6%로 가장 높습니다. 7월 1일부터 10일까지 진행된 여름 세일 기간과 겹쳐, 프로모션 효과가 반영된 것으로 보입니다."
}
```

- `campaign_analysis`는 `\n\n`으로 구분된 블록으로 구성된다.
- 첫 블록은 인트로 문단 → `<p>`로만 렌더링한다.
- 이후 블록은 **첫 줄이 캠페인명(+매체)** → `<h4>` 소제목으로, 나머지 문장은 `<p>`로 렌더링한다.

## 렌더링 규칙
- 강조 수치는 `<strong>` 태그 사용
- `⚠`로 시작하는 문장은 `color:#d97706`(주황) 처리
- 캠페인 소제목에는 매체명을 괄호로 함께 표기한다 (예: "리타겟팅_구매고객 (Meta Ads)") —
  같은 이름의 캠페인이 다른 매체에 있을 수 있으므로 구분을 위해 항상 붙인다.
- 데이터가 비어있으면 "데이터 준비 중" 카드로 대체하고 임의로 채우지 않는다.
