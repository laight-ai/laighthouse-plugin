# Breezm Daily Section 2: Executive Summary

**report_type:** `daily` — **브리즘(airbridge 기반, type-b) 전용** (항상 포함). 실무자가 오늘
무엇을 점검·조치해야 하는지 판단할 수 있도록, **전날(D-1) 대비 오늘(D-0)의 변화**와 캠페인/
광고그룹 단위의 특이사항 중심으로 쓴다. `mtd`의 Executive Summary(섹션 2)와 HTML 골격은
동일하다 — 카드 하나 안에 평범한 불릿 리스트(`<ul><li>`)로 렌더링한다. 다만 데일리 보고서는
"월초~기준일" 누적이 아니라 **D-1 vs D-0 하루 단위 비교**가 중심이라는 점에서 분석 항목 구성이
`mtd`와 다르다 (페이싱/매체별 특이사항 항목은 없다 — 대신 캠페인/광고그룹 단위 일일 변화를
본다).

## 응답 데이터 구조

```json
{
  "executive_summary": "7월 15일의 전체 ROAS는 122.4%로, 전날(98.1%) 대비 개선되었습니다.\n7월 1일부터 10일까지 진행된 여름 세일 기간이 끝난 이후에도 광고 매출이 완만한 상승세를 유지하고 있습니다.\nMeta Ads의 여름 신제품 런칭 캠페인은 광고비가 전날 대비 +3.7% 늘었지만 예약 CPA는 오히려 -5.8% 개선되어, 예산을 더 배분해볼 만한 신호로 보입니다.\nGoogle Ads의 여름 성수기 검색광고는 CTR이 전날 대비 -0.1%p 하락하고 예약 CPA도 +3.3% 상승해, 소재 또는 타겟팅 점검이 필요한 상황입니다."
}
```

- `executive_summary` 값이 문자열이면 그대로 `<p>`로 렌더링
- 줄바꿈(`\n`) 기준으로 분리하여 각 줄을 `<li>`로 렌더링

## 렌더링 규칙
- `executive_summary` 문자열을 `\n` 기준으로 split → 각 줄을 `<li>` 태그로 변환
- 빈 줄은 건너뜀
- `⚠`로 시작하는 항목은 `color:#d97706`(주황) 처리 — 예: 목표 미등록으로 평가가 어려운 경우,
  캠페인/광고그룹의 지표가 비정상적으로 나쁜 경우 등 실무자가 주의해야 할 항목에 붙인다
- 강조 수치는 `<strong>` 태그 사용
- 항목은 항상 이 순서(① ROAS vs 목표(또는 D-1 대비) → ② 광고 매출 특이사항 → ③ 캠페인/
  광고그룹 특이사항 2~4개)로 렌더링한다 — 순서를 섞지 않는다. 전체 문장 수를 4개로 고정하지
  않는다 (①·②는 한 문장씩, ③은 선정된 캠페인/광고그룹 수만큼).
