# Monthly Section 5: 제품 판매 성과의 심층 분석

**report_type:** `monthly` (항상 포함)

mtd(MK)의 `mtd-section-5-product-deep-dive.md`와 HTML 골격은 동일하지만, 데이터 소스와 톤이
다르다:
- mtd는 `get_naver_item_sales_daily`(일일 카테고리 매출) 하나만 근거로 카테고리별 최대 두 문장씩
  세세하게 분석한다.
- monthly는 **monthly-section-6(카테고리별 월간 매출액 비교)의 전월 대비 증감률**과
  **monthly-section-7(일일 카테고리별 매출 현황)의 이번 달 일별 추이**를 함께 근거로 삼아, 개별
  카테고리보다 **"이번 달 제품 판매 트렌드 전체"를 하이레벨로 요약**한다.

---

## 텍스트 생성: AI가 직접 작성 (`df_dify` MCP 호출 안 함); 수치 소스는 monthly-section-6/7

⚠️ **`df_dify` MCP 서버는 현재 호출하지 않는다** (연결 불안정으로 타임아웃 시 빈 응답이 돌아옴).

```
작성 순서:
1. monthly-section-6(카테고리별 월간 매출액 비교)이 이미 가공한 상위 5개+기타 카테고리의
   curr/prev/change_pct 데이터를 재사용한다.
2. monthly-section-7(일일 카테고리별 매출 현황)이 이미 호출한 get_naver_item_sales_daily
   (이번 달 일별) 결과를 재사용한다.
3. dify 호출 없이, 1~2의 수치 데이터를 근거로 AI가 analysis_of_category_performance 텍스트를
   직접 작성한다. mtd(카테고리당 최대 두 문장)보다 하이레벨로 쓴다:
   3-1. 첫 블록(Overview)에 "이번 달 제품 판매 성과 트렌드 요약" 문단을 반드시 넣는다 — 전체 카테고리 합산 매출의 전월 대비 증감, 가장 빠르게 성장한 카테고리와 가장 둔화된 카테고리를 각 1개씩 수치와 함께 짧게 언급한다.
   3-2. 이후 블록은 카테고리 단위가 아니라 "성장 카테고리" / "둔화 카테고리" / "특이사항"처럼 주제 단위로 묶어 각 1~2문장으로 서술한다 (mtd처럼 5개
        카테고리를 전부 개별 소제목으로 나열하지 않는다 — high-level 요약이 목적이다).
   3-3. monthly-section-7의 일별 추이에서 특정 카테고리가 급등/급락한 날이 있으면 'list_promotions'를 근거로 설명한다. 만약 'list_promotions'에서 근거를 찾을 수 없다면 3-3은 생략한다. 
```

## 응답 데이터 구조

```json
{
  "analysis_of_category_performance": "Overview\n2026년 3월 전체 매출은 13억 9,000만 원으로, 직전월 대비 4.9%p 감소하였으나 전년 동기 대비로는 18.9%p 높은 수준입니다. 카테고리별로는 단백질보충제가 4개월 연속 성장세를 이어가고 있습니다.\n\n성장 카테고리\n단백질보충제와 우유/요거트는 각각 전월 대비 17%, 18.8% 증가하며 뚜렷한 성장세를 보였습니다...\n\n주의가 필요한 신호\n두유 카테고리는 4개월 연속 매출 감소세이며, 프로모션 대상에 포함되지 않아..."
}
```

- `analysis_of_category_performance`는 `\n\n`으로 구분된 블록으로 구성
- 각 블록의 첫 줄이 소제목(`Overview`, `성장 카테고리`, `주의가 필요한 신호` 등)이면 `<h4>`로
  렌더링
- 나머지 문장은 `<p>`로 렌더링

## DOCX 섹션

```json
{
  "type": "text",
  "heading": "제품 판매 트렌드 분석",
  "body": "{analysis_of_category_performance}"
}
```

- `analysis_of_category_performance`는 `\n\n`으로 구분된 블록 문자열(첫 줄이 `Overview` 또는
  주제 소제목, 나머지가 설명)을 그대로 `body`에 넣는다 — 정적 문서에서는 소제목/본문을 별도
  마크업으로 나누지 않고 하나의 텍스트 블록으로 낸다.
- 강조하고 싶은 수치가 있으면 문장 자체에 자연스럽게 녹여 쓴다.
- 섹션 타이틀은 "제품 판매 트렌드 분석"이다.
