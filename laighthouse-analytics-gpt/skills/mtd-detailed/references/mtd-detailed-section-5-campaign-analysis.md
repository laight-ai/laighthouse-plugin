# MTD Section 5: 캠페인 분석 (Campaign Analysis)

> 🧩 ChatGPT/Codex: 캡처 훅이 없는 환경에서는 응답이 원본 JSON 봉투로 온다 — `json`에 그대로
> 넘긴다(`shared/references/gpt-large-response-guardrail.md`).

**report_type:** `mtd-detailed` (항상 포함). 표로 보여주는 섹션 7과 달리 **서술형**으로
특이사항과 액션 아이템을 짚는다.

> ℹ️ HTML 렌더링(`\n\n` 블록 → 인트로 `<p>` + 캠페인별 `<h4>`+`<p>`, `⚠` 주황색)은 빌더가
> 한다 — 모델은 아래 규칙으로 텍스트만 작성해 빌더 입력 JSON의 `s5.campaign_analysis`에 넣는다.

## 텍스트 생성: AI가 직접 작성 (신규 MCP 호출 없음)

⚠️ **`df_dify` MCP 서버는 호출하지 않는다** — 전부 다른 섹션 응답을 재사용한다:

- section-7의 **캠페인 레벨 응답**(`group_by:["media","campaign_name"]`, month grain,
  `day_offset`, 전월 1일~target_date) — 행의 `month`가 당월이면 MTD 값, 전월이면 전월 동기 값이다.
  각 행에 봉투의 전체 지표(역할 키 + 서버 비율 지표)가 들어 있다 — 캠페인 행의 비율은 그 행의
  서버 값을 그대로 쓴다(이미 캠페인 단위로 계산됨).
  - 응답이 원본으로 왔으면 그대로 읽는다. **캡처 스텁(`[laighthouse-capture-hook] ... 저장됨:
    <경로>`)으로 왔으면 그 파일을 Read로 열지 않는다** — Bash(python)로 그 경로를 읽어 필요한
    행만 뽑는다(예: 당월 광고비 상위 캠페인 20개와 그 캠페인의 전월 행을 역할 키·비율 키만 골라
    출력). 전문을 컨텍스트로 가져오지 않는다.
- 이 섹션에서만 쓰는 파생 지표는 봉투에 없을 때만 그 자리에서 원자 값으로 계산: `CPC` = 광고비 ÷
  클릭(클릭 0이면 N/A), `평균단가`(객단가) = 매출 ÷ 전환(0이면 N/A). "전환"은 conversion 역할 키
  값이다 — conversion 역할이 없는 브랜드면 전환·CPA·평균단가는 다루지 않는다.
- section-4의 `list_promotions` 응답 — MTD 기간과 겹치거나 직전에 끝난 프로모션 확인용.

**모드별 기준** (`generic-report-pattern.md` 7절): 매출 있음 → ROAS·CPA·전환·평균단가·CTR·CPC,
매출 없음 → CTR·CPC·클릭·노출(·전환) 중심 — **매출·ROAS·평균단가는 언급하지 않는다**.

**작성 원칙 — 반드시 지킬 것**:

1. **광고비가 큰 캠페인을 우선 검토**하되 광고비 순 나열 금지 — 같은 매체 내 다른 캠페인 대비,
   또는 전월 동기 대비 효율 지표가 확연히 높거나 낮아 "특이사항"으로 부를 만한 것만 고른다.
   ⚠️ **매체를 가로질러 CTR/CPC를 직접 비교하지 않는다** — 지면·과금 구조가 달라 스케일이
   다르다(같은 매체 내에서만). ROAS·CPA·전환은 매체 간 비교 가능.
2. 특이사항마다 **원인 가설과 해결 방향을 간결히** 덧붙인다. 해당 캠페인 기간과 겹치거나 직전에
   끝난 프로모션이 있으면 **프로모션명과 기간을 함께 언급**하며 연계 서술(효과가 뚜렷하지
   않으면 그 사실 그대로).
3. **truism 금지** — 모든 문장은 구체적 수치를 근거로. 강조 수치는 `<strong>` 사용 가능.
4. 캠페인은 **2~4개만** 심층 분석 (전체를 다 훑지 않는다). 특이사항이 없으면 억지로 채우지
   않는다.
5. 새로운 수치를 지어내지 않는다 — 근거 없는 원인 추정은 "확인이 필요하다" 수준까지만.

## 빌더 `s5.campaign_analysis` 형식

`\n\n`으로 구분된 블록 문자열 — 첫 블록은 인트로 문단(빌더가 `<p>`), 이후 블록은 첫 줄이
캠페인명+매체(빌더가 `<h4>`), 나머지 문장이 본문(`<p>`). 캠페인 소제목에는 매체명을 괄호로
항상 함께 표기한다 — 매체명은 응답 `media` 값 **그대로**(접미사·번역 없음, 예:
`<campaign_name 값> (<media 값>)`) — 같은 이름이 다른 매체에 있을 수 있다. 금액은 `currency`
기호로 표기한다.

```json
{ "campaign_analysis": "특이사항이 확인되는 2개를 선정했습니다.\n\n<campaign_name 값> (<media 값>)\n광고비 {currency}9,800,000으로 매체 내 2번째로 크지만, 전환이 0건으로..." }
```

- 데이터가 없으면 `s5` 자체를 넣지 않는다 → "데이터 준비 중" 카드.
